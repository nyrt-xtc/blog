Xposed Edge Pro手势

2026-05-16 优化 Xposed edge pro 手势

Xposed Edge Pro 是一款 Xposed 模块，可以实现各种复杂的手势和自动化操作。
文章结尾附有我的配置文件下载链接。

手势设置

  1. 打开 Xposed Edge Pro，勾选“手势”并点击进入。
  2. 勾选要触发的区域（如左边缘、右下等），然后点击该区域进入设置。
  3. 选择触发方式（如右划、左划、双击等），在弹出的动作列表中选择要执行的触发动作。

示例：设置右划返回手势
选择左边缘 → 选择右划 → 在动作列表中选择返回

我的手势配置

  • 左边缘右划：返回
  • 上右下划：打开快捷面板
  • 下中双击：关闭前台应用
  • 下中上划：截屏

按键设置

按键设置在小天才手表上用处不大，因为手表按键较少。
不过有一个玩法：利用“翻起手表”来启动应用等操作。

  1. 勾选并进入“按键设置”。
  2. 点击最底下的“添加”，选择翻起手表。
  3. 确认后勾选该项，选择单击，再选择你想要执行的动作。

快捷面板

快捷面板是一个 4×4 的面板，可以放置很多动作，你也可以自定义为 2×2 或 3×3 的布局。
注意：“启动快捷面板”本身是一个动作，需要先在手势或按键里绑定它。
设置好触发方式后，点击“快捷面板”即可配置每一行按钮对应的动作。

快捷面板动作推荐

  • 剪贴板：查看和管理剪贴板内容
  • 全局复制：点击后点按屏幕上的文字即可复制（适用于无法直接复制的场景）
  • 开关移动数据 / 开关 Wi-Fi
  • 保持亮屏：触发后屏幕常亮，可在通知栏手动关闭，或锁屏一次即可恢复
  • 游戏模式：触发后暂时禁用手势，避免误触，可在通知栏重新开启
  • 展开通知栏
  • 上一输入法：快速切换输入法
  • 应用抽屉：方便打开应用（即使桌面被禁用也能用）
  • 画笔：在屏幕上涂鸦标注
  • 截屏

更多触发器

软件中还提供更多条件触发功能。
推荐示例：

  • Wi-Fi 断开时，用 Toast 提示“WiFi 已断开”
  • 连接上 Wi-Fi 时，用 Toast 提示“WiFi 已连接”

此外，该软件还支持应用冻结等高级功能。
如果你有其他好玩的用法，欢迎补充。
